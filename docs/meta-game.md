# 元游戏：货币 / 商店 / 连胜 / 勋章

> 本文是这套系统的**数值契约**。改价格、改奖励、改勋章条件，先改这里，
> 再改 `Core/ToolCatalog.cs` 与 `Core/GameProgress.cs`，最后跑 `--selftest`。

## 1. 一条原则

**奖励只由「虫子的阶段」决定，工具不提供任何倍率。**

理由：整个应用的核心激励是"越早清越值钱"。如果给进阶工具加金币倍率，
"卵 100 / 苍蝇 10" 这条激励就会被工具强度盖住，数值也再没法对账。
进阶工具改变的只有两件事：**一次能清几只**、**出手间隔**。

## 2. 击杀奖励

| 阶段 | 奖励 | 说明 |
|:--|--:|:--|
| 🥚 卵 | **100** | 需求明确 |
| 🐛 蛆 | **50** | 需求明确 |
| 🛖 蛹 | **25** | 需求未给数字；按"越早越值钱"的单调性插值 |
| 🪰 苍蝇 | **10** | 需求明确 |
| 已完成 | 0 | 不会重复结算 |

「金币只来自亲手击杀」是刻意设计：在任务列表里点「完成」算**打卡**（续连胜、
进日历），但**不发钱**。这样"拍死它"和"点完成"各有各的意义。

## 3. 商店

| 工具 | 价格 | 形状 | 覆盖 | 冷却 |
|:--|--:|:--|:--|--:|
| 苍蝇拍 | 0（初始） | 单点 | 光标下最近一只 | 无 |
| 杀虫喷雾 | 1,000 | 圆形 | 半径 130 px | 0.90 s |
| 唐太刀 | 10,000 | 十字 | 横竖各 240 px、半宽 46 px | 0.55 s |
| 霓虹激光枪 | 50,000 | 横向光带 | 全屏宽、上下 42 px | 1.10 s |

- 购买成功即自动装备；重复购买会被拒绝且不扣钱。
- 装备只能选**已拥有**的工具；存档里出现未知 id 时退回苍蝇拍。
- 光标由 `Render/CursorFactory.cs` 程序化生成 `.cur` 字节流（零位图素材），
  每件工具一个热点：拍面中心 / 喷嘴 / 刀尖 / 枪口。

## 4. 连胜（多邻国式）

**活跃日** = 当天「击杀 > 0」**或**「完成任务 > 0」。

- 同一天多次击杀只记一天；
- 昨天活跃、今天还没动 → 连胜**仍然有效**（还没到判定时刻）；
- 跳过一整天 → 连胜清零，`BestStreak` 保留；
- 系统时间被往回调（gap ≤ 0）时不清零，避免改时间直接毁掉记录。

热度等级由当前连胜换算，只是展示层，不改变任何数值：

| 连胜 | 0 | 1–2 | 3–6 | 7–13 | 14–29 | ≥30 |
|:--|:--:|:--:|:--:|:--:|:--:|:--:|
| 等级 | 0 | 1 | 2 | 3 | 4 | 5 |
| 文案 | 熄灭 | 余温 | 小火 | 旺火 | 烈焰 | 燎原 |

## 5. 勋章（10 枚）

| # | 名称 | 条件 |
|--:|:--|:--|
| 1 | 第一拍 | 累计击杀 ≥ 1 |
| 2 | 破壳者 | 卵击杀 ≥ 10 |
| 3 | 蛆之克星 | 蛆击杀 ≥ 25 |
| 4 | 灭蝇专家 | 苍蝇击杀 ≥ 50 |
| 5 | 四象皆斩 | 卵 / 蛆 / 蛹 / 苍蝇各 ≥ 10（取四者最小值） |
| 6 | 三日不辍 | 最长连胜 ≥ 3 |
| 7 | 七日之约 | 最长连胜 ≥ 7 |
| 8 | 月度铁人 | 最长连胜 ≥ 30 |
| 9 | 百人斩 | 累计击杀 ≥ 100 |
| 10 | 千虫之主 | 累计击杀 ≥ 1000 |

勋章**不维护"已达成"布尔**，每次都从计数派生；`UnlockedMedals` 只用来记录
首次解锁日期和避免重复弹通知。因此"标题上的 4/10"和"墙上亮着的 4 张卡"
永远一致（`UnlockedMedalCount` 也是按达成条件实时数）。

## 6. 数据落盘

`state.json` 升到 **v4**，新增 `progress` 节点：

```json
"progress": {
  "coins": 0,
  "totalCoinsEarned": 0,
  "totalSpent": 0,
  "totalKills": 0,
  "killsEgg": 0, "killsLarva": 0, "killsPupa": 0, "killsFly": 0,
  "tasksCompleted": 0,
  "currentStreak": 0, "bestStreak": 0,
  "lastActiveDate": "2026-10-26",
  "days": { "2026-10-26": { "kills": 3, "completed": 3, "coins": 300,
                           "egg": 1, "larva": 1, "pupa": 0, "fly": 1 } },
  "ownedTools": ["swatter", "spray"],
  "equippedTool": "spray",
  "unlockedMedals": { "first-swat": "2026-10-26" }
}
```

- v1–v3 的存档缺 `progress`，加载时补一个全新对象，不抛异常；
- `days` 只保留最近 **400 天**；
- **清空任务不会清空钱包与勋章** —— 那是长期元游戏进度，
  否则"清空"会变成把已花掉的钱再赚一遍的漏洞。

## 7. 交互链路

```
鼠标移动 ──> 0.18s 驻留 ──> 悬停名牌（名字 · 阶段 · +奖励）
                          └─ 3.0s 驻留 ──> 详情气泡（规格 §14）
点击 ──> 工具形状判定 ──> 移除生物 ──> 洁净消除特效（光环 + 光尘 + 「+N」）
      └─> 引擎 Complete ──> 只有成功才发钱 ──> 连胜 / 日历 / 勋章 ──> 落盘
```

**记账顺序是刻意的**：先让引擎真的完成任务，再发货币。引擎拒绝
（任务已不存在 / 已完成）时这一只不产生任何货币，所以点空刷不出钱。

### 两个必须记住的命中坑（1.3.1 修）

1. **分层窗口按 alpha 做逐像素命中。**
   `AllowsTransparency=True` 的覆盖层，如果背景是 `Transparent`（alpha=0），
   Windows 会认为"这里没有窗口"，点击直接漏给桌面 —— 只有正好落在虫子实心像素上
   才收得到。用户感觉就是"点它旁边的空白完全没反应"。
   解法：`RootCanvas.Background="#01000000"`（alpha=1/255，肉眼不可见），整屏可命中。

2. **蛆的 `Position` 是头部，不是重心。**
   绘制从 `Position` 沿朝向的反方向延伸约 `0.95 × Size`。
   判定圆心若留在头部，用户按视觉重心点身体中段就会偏出半径。
   解法：`CreatureVisual.HitCenter` 对蛆沿朝向后移 `0.42 × Size`；
   悬停与点击**共用**它，避免"悬停能看到名字、点击却打不中"的分裂手感。

## 8. 验收

```bash
MaggotTask.exe --selftest     # 594 项，含元游戏 33 项
MaggotTask.exe --diag-game    # 打印数值快照并并排打开军械库 / 荣誉殿堂
MaggotTask.exe --diag-kill    # 把一只卵钉在 (500,430)，供外部脚本端到端点击验证
```
