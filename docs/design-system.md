# 蛆虫任务 · 设计系统 v1.0

面向 `ui-ux-pro-max` 的 `organic-biophilic` 风格谱系，但**翻转到暗面**：
标本缸、防腐液、生物荧光。不是 SaaS，不是赛博朋克 —— 是**湿的、有机的、活的**。

## 0. 一条硬约束（决定了后面所有视觉决策）

虫群浮在**任意桌面内容之上** —— 可能是纯白网页，也可能是纯黑终端。
所以每个生物都必须：

1. 有 **1.5px 深色描边** `rgba(20,24,16,0.55)` —— 保证在浅色背景上不消失
2. 有 **柔和外阴影** `rgba(0,0,0,0.45) blur 6px offset(0,2)` —— 保证在杂乱背景上浮起来
3. 身体用**中间调**（不是纯白也不是纯黑），两端背景都能读

违反这条，产品在任何真实桌面上都是糊的。

## 4. 动效

| Token | 时长 | 用途 |
|---|---|---|
| `--dur-instant` | 90ms | 按压反馈 |
| `--dur-fast` | 160ms | hover、状态切换 |
| `--dur-base` | 240ms | 面板展开、卡片进出 |
| `--dur-slow` | 380ms | 阶段跃迁、页面切换 |
| `--dur-hero` | 620ms | 爆浆、孵化庆祝 |

缓动：
- 进场 `cubic-bezier(0.05, 0.7, 0.1, 1)`（快出慢停）
- 出场 `cubic-bezier(0.3, 0, 0.8, 0.15)`（出场比进场快 30%）
- 生物蠕动：正弦，相位由 `seed` 决定，**永不使用统一时长**

**必须支持 reduced-motion**：开启后
- 生物停止蠕动/飞行，改为静止姿态 + 缓慢呼吸（周期 ≥ 4s）
- 阶段跃迁直接跳到终态
- 爆浆动画退化为一次淡出

## 5. 生物绘制规格

所有生物**程序化矢量绘制**，不使用位图资源。
坐标原点为生物中心，`size`（= 1.0）为基准直径。

### 基准直径按平台取值（实测修订）

| 平台 | `size = 1.0` 对应 | 在典型屏幕上的占比 | 换算 |
|:--|:--|:--|:--|
| Android | **22 dp** | 1080px 宽手机上约 6% | `px = 22 × density` |
| Windows | **34 px**（WPF 设备无关单位） | 1536px 宽桌面上约 2.2% | 直接就是 34 |

> **为什么两端不一样**：最初统一用 22，结果在桌面上实测只有 1.4% 屏宽，
> 渲染出来像一粒灰尘，完全没有「视觉压力拉满」的效果。
> 手机屏幕小、观看距离近，22dp 足够；桌面显示器大、距离远，需要更大的绝对值。
> 这和 iOS 44pt / Android 48dp 的差异是同一类问题 —— **视觉尺寸要按观看条件定，不是按数字统一。**

**生物内部所有长度比例都相对于 `size`**（如蛆全长 ≈ `1.38 × size`），
所以在两端换一个基准值，整套形态会自动等比缩放，不需要改形状代码。

### 卵 EGG
- 椭圆，长短轴比 1 : 1.25（竖直）
- 充填 `--egg`，右下 1/3 用 `--egg-deep` 做体积
- 左上高光：白色 55% 透明椭圆
- 呼吸：`scale = 1 + 0.04 * sin(t*1.6 + seed)`
- `rot > 0.08` 起叠加暗斑：`floor((rot-0.08)*30)` 个 `#8A7F5E` 小点，位置由 seed 决定

### 蛆 LARVA
- 6 节，沿一条正弦脊线排列，半径由头到尾 `1.0 → 0.72` 递减
- 充填 `--larva`，每节底部叠 `--larva-deep` 月牙
- 分节缝：`--larva-deep`，宽 1.5，圆头
- 头节更暗（`--larva-deep`），前端两条深色口钩
- 蠕动：第 `i` 节横向偏移 `amp * sin(phase + i * 0.9)`，`amp = 0.10 * size`
- 拱行：整体沿朝向缓慢平移，速度 `6 px/s @1x`，随机改变朝向

### 蛹 PUPA
- 圆角胶囊，长宽比 1 : 1.8，圆角 = 宽度一半
- 充填 `--pupa`，纵向渐变到 `--pupa-deep`
- 3 条横向节纹，`--pupa-deep`
- 顶部细长高光条（白 30%）
- 静止。每 3.5–6 秒做一次 `±2°` 的抽动，持续 120ms

### 苍蝇 FLY
- 腹部：椭圆 `--fly`，长宽比 1 : 1.4
- 胸部：圆 `--fly`，略小
- 头：小圆 + 两只 `#B33A2E` 复眼
- **躯干描边 `--fly-rim` 1.2px**（暗背景可见性的关键）
- 双翅：椭圆，充填 `--wing-a → --wing-b` 线性渐变，35% 透明
- 扇翅：`scaleY = |sin(t * 42 + seed)|`，最小 0.18
- 6 条腿：3px 线段，深色

### 通行规则
每只生物绘制顺序：`阴影 → 描边 → 本体 → 高光 → 细节`。

**阴影必须比本体轮廓大一圈**（各阶段约 `1.08×` 本体的包围盒），
否则投影会被身体完全盖住，等于没画。
有朝向的阶段（蛆、苍蝇）**阴影也要跟着旋转**，否则身体斜着、影子横躺，一眼假。

各阶段阴影包围盒（相对 `size`）：

| 阶段 | 本体 | 阴影 |
|:--|:--|:--|
| 卵 | `0.80 × 1.00` | `0.88 × 1.10` |
| 蛆 | `1.38 × 0.43` | `1.45 × 0.52`（随朝向旋转） |
| 蛹 | `0.42 × 0.76` | `0.52 × 0.86` |
| 苍蝇 | `1.33 × 0.68` | `1.45 × 0.70`（随朝向旋转） |

## 6. 苍蝇飞行动线

轻量 boids，不做群体智能，只求"烦人"：

```
wanderAngle += rand(-1, 1) * 0.35 * dt * 60 * 0.016
desired      = dir(wanderAngle) * speed
vel          = lerp(vel, desired, 0.06)
每 1–3 秒随机一次冲刺：vel += randUnit() * (60 + 90*min(rot,1))

speed = 70 + 60 * min(rot, 1)        // px/s @1x，越烂越狂躁
边缘规避：距边界 < 60px 时，向内的转向力随距离线性增强
```

蛆：几乎不动，`6 px/s` 缓慢拱行，碰到边缘折返。
卵 / 蛹：完全静止（原地轻微动画）。

**生物位置按 task id 持久化在内存**，阶段变化时不重置位置（避免瞬移）。
新生物从随机的屏幕边缘外飞入。

## 7. 控制面板

### 布局（自顶向下）

1. **标题行**：`蛆虫任务` + 运行状态点（绿=运行 / 灰=暂停）
2. **数字条**：四个计数 —— 卵 / 蛆 / 蛹 / 苍蝇，等宽字体，各配阶段色圆点
3. **腐烂压力条**：横向 stacked bar，显示全部任务按阶段占比 + 整体平均 rot
4. **主行动**：`启动 / 暂停`（`--primary`，整行宽，高 44）
5. **腐化倍速**：滑块，左侧标签 `腐化倍速`，右侧 `×1.0`
6. **次级行动行**：`新建任务` · `重置` · `清空`（`清空` 用 `--danger`，需二次确认）
7. **开关行**：`穿透` · `音效` · `通知`

### 交互规则

**目标尺寸按输入方式定，不是一个数字通吃**（v1.1 修订）：

| 输入方式 | 最小目标 | 说明 |
|:--|:--|:--|
| 触摸（Android / 触摸屏） | **48 × 48 dp** | 手指的接触面比视觉焦点大得多 |
| 指针（Windows 桌面鼠标） | **32 × 32 px** | 与 Win32 / Fluent 的标准按钮高度一致；面板标题栏按钮 52×32 合规 |

> 初版把「≥44×44」写成了通用规则，这是错的 —— 那是移动端触控 guideline。
> 桌面鼠标的精度远高于手指，强行套 44 只会让紧凑面板变得臃肿。
> 按平台取正确值，而不是取一个折中的大数字。

- 按压反馈 90ms 内出现（ripple/opacity）
- 面板可拖动，**拖动只挂在标题文字上，按钮放在独立列** —— 结构上就不可能被误当成拖动
- 关闭悬浮层 ≠ 停止模拟（服务继续跑）

### 危险动作
- `清空` 必须二次确认，且确认文案给出具体数量：「将永久删除 **N** 个任务」
- 主按钮不做确认；`重置` 可撤销提示（3 秒内）

## 10. 应用图标（Windows）

**设计**：延续"标本缸"语言 —— 深色圆角缸体 + 缸内一只苍蝇（薄荷描边 + 半透明 V 字翅）
+ 红色复眼。**红元素承担两件事**：复眼是 16px 下唯一还认得出的特征（小尺寸下刻意放大 1.34×），
右下角的红色**腐化弧**（仅 ≥64px）承接"腐烂进度"的语义。

**硬约束**（与生物绘制同源）：

- 16px 下必须仍能读出"这是一只虫"——腿、翅脉、高光在小尺寸档一律省略；
- 缸体自带深色底：浅色与深色的任务栏/资源管理器背景上都不糊；
- 不引外部位图：图标由 `Render/AppIconFactory.cs` **程序化生成**。

**尺寸与编码**：16/20/24/32/40/48/64/128/256 共 9 档，每档**单独绘制**（不是缩放同一张图）；
≤64 用 32bpp DIB（兼容性最好），128/256 用 PNG 压缩（`RenderTargetBitmap` 只支持预乘 alpha，
写 DIB 前会反预乘）。

**重新生成**（改完画法后跑一次，产物直接覆盖并被 csproj 引用）：

```
MaggotTask.exe "--appicon=Assets\maggot.ico" "--preview=<目录>"
```

**取用**：exe 文件图标 = csproj 的 `ApplicationIcon`；窗口图标（任务栏/Alt-Tab）与
托盘图标都从**同一份嵌入资源**读取（`AppIconFactory.LoadImageSource/LoadTrayIcon`），
避免"三处各画一套"的漂移；读取失败静默跳过 —— 图标永远不该导致启动失败。

**尺寸标尺**：`docs/images/app-icon-sizes.png`（1×-放大 3 倍，浅底/深底各一排）。
