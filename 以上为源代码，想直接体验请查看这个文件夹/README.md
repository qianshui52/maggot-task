## Windows 版 · 1.3.1

**系统要求**

- Windows 10 / 11（64 位）
- **.NET 7 桌面运行时（Desktop Runtime）** —— 这是唯一的前置条件
- 约 5 MB 磁盘空间，无需管理员权限

**第一步：装运行时**（已经装过就跳过）

任选一种：

```powershell
winget install Microsoft.DotNet.DesktopRuntime.7
```

或者从官网下载安装：<https://dotnet.microsoft.com/zh-cn/download/dotnet/7.0> → 选 **.NET Desktop Runtime 7.x** → **x64**。

> 怎么判断装没装？双击 `MaggotTask.exe`，如果弹出
> 「You must install .NET Desktop Runtime」就是没装。

**第二步：解压**

把 `MaggotTask-Windows-1.3.1.zip` **完整解压到一个文件夹**（例如 `D:\MaggotTask\`）。

⚠️ **不要在压缩包里直接双击 exe** —— 那样 exe 找不到旁边的 `MaggotTask.dll`，会启动失败。

**第三步：运行**

双击 `MaggotTask.exe`。右下角托盘出现一只虫子的图标，控制面板同时弹出。

- 如果 Windows 弹出「已保护你的电脑」（SmartScreen）：这是因为安装包**没有代码签名**，
  点「更多信息」→「仍要运行」即可。
- 首次运行会生成 `%APPDATA%\MaggotTask\state.json`，所有数据只在这一台机器上。

**开始玩**

1. 面板里点「新建任务 / 任务列表」写下你要做的事；
2. 默认**鼠标穿透是开着的**（虫子不会挡你点任何东西）；
3. 想亲手拍死它们：把面板上的「穿透」开关**关掉**，光标会变成苍蝇拍；
4. 鼠标停 0.2 秒会浮出名牌，点一下就清掉一只，掉金币；
5. 面板上的「军械库」「荣誉墙」是 1.3.0 新增的：买工具、看连胜日历、拿勋章。

**卸载**

关掉程序 → 删除解压出来的文件夹 → 想连数据一起删就删掉 `%APPDATA%\MaggotTask\`。

## Android 版 · 1.2.10

**系统要求**

- Android 8.0（API 26）及以上
- 约 8 MB 安装空间
- 需要允许「安装未知来源应用」与「显示在其他应用上层」两项权限

**安装步骤**

1. 把 `MaggotTask-Android-1.2.10.apk` 传到手机（数据线 / 微信文件传输 / 网盘都行）；
2. 用文件管理器点开它；
3. 首次会提示「未知来源」，按引导允许当前文件管理器安装；
4. 打开应用 → 按引导授予**悬浮窗权限**（设置里通常叫「显示在其他应用上层」）；
5. 点「让虫群上桌」，回到桌面就能看见它们了。

**注意**

- 国产 ROM（vivo / OPPO / 小米）可能杀后台，建议把电池策略设为「无限制」；
  悬浮窗上不了桌时应用会自动退回「应用内显示」，并在体检卡写明原因。
- 本 APK 使用仓库内的测试签名（`android/app/maggot-shared.keystore`），
  仅用于分发体验，**不要**拿它去上架应用商店。

**卸载**

长按图标卸载即可。数据随应用一起删除。

## 文件命名规则

```
MaggotTask-Windows-<版本号>.zip      Windows 绿色免安装包（解压即用）
MaggotTask-Android-<版本号>.apk      Android 安装包
```

- 版本号与源码里的 `versionName` / `csproj <Version>` 一致；
- 正常发版**新增**文件、保留旧版本，方便回退对比；
- **修 bug 的补丁会直接替换同平台的旧文件**——不把有缺陷的构建留在仓库里让人误下。

Get-FileHash .\MaggotTask-Windows-1.3.1.zip -Algorithm SHA256
