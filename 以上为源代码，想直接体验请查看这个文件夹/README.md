# 直接体验

这里只有能直接装、直接跑的文件。源码在仓库根目录的 `android/` 和 `windows/`，这个文件夹不参与构建。

## 1.3.2 改了什么

- 点「完成」不发钱：做完 6 个任务货币一分没动。现在列表完成和桌面击杀走同一套记账。
- 苍蝇拍点了没反应：穿透开着时窗口收不到鼠标事件，光标也不会换。现在光标靠近虫子会自动接管点击，不用先去关穿透。

上两个版本的修复（蛆点不死、战果改标本缸）也都包含在内。下过旧版的直接换这个。

## 选平台

| 设备 | 文件 | 大小 |
|:--|:--|--:|
| Windows 10 / 11 电脑 | `MaggotTask-Windows-1.3.2.zip` | 约 0.8 MB |
| Android 8.0 及以上 | `MaggotTask-Android-1.2.10.apk` | 约 7.0 MB |

点进这个文件夹，在文件名右侧点 Download 就行。

## Windows 版 1.3.2

**系统要求**

- Windows 10 / 11，64 位
- .NET 7 桌面运行时，这是唯一的前置条件
- 占 5 MB 左右，不需要管理员权限

**第一步，装运行时**（装过就跳过）

```powershell
winget install Microsoft.DotNet.DesktopRuntime.7
```

或者去官网 <https://dotnet.microsoft.com/zh-cn/download/dotnet/7.0> 选 .NET Desktop Runtime 7.x，再选 x64。

判断装没装很简单：双击 `MaggotTask.exe`，如果弹出「You must install .NET Desktop Runtime」就是没装。

**第二步，解压**

把 zip 完整解压到一个文件夹，比如 `D:\MaggotTask\`。

不要在压缩包里直接双击 exe。那样 exe 找不到旁边的 `MaggotTask.dll`，起不来。

**第三步，运行**

双击 `MaggotTask.exe`，右下角托盘出现虫子图标，控制面板同时弹出。

第一次运行 SmartScreen 可能拦一下，因为安装包没有代码签名。点「更多信息」再点「仍要运行」。

数据存在 `%APPDATA%\MaggotTask\state.json`，只在这台机器上。

**怎么玩**

1. 在面板里点「新建任务 / 任务列表」，写下要做的事
2. 虫子会爬在桌面上，默认点击穿透，不挡你点任何东西
3. 想拍死它，把光标移到虫子上，指针会变成苍蝇拍，点一下就行
4. 停 0.2 秒浮出名牌，停满 3 秒出详情气泡
5. 面板上的「军械库」「荣誉墙」是 1.3.0 加的，买工具、看连胜、拿勋章

**卸载**

关掉程序，删掉解压出来的文件夹。想连数据一起清就删 `%APPDATA%\MaggotTask\`。

## Android 版 1.2.10

**系统要求**

- Android 8.0（API 26）及以上
- 约 8 MB 空间
- 需要允许「安装未知来源应用」和「显示在其他应用上层」

**安装**

1. 把 apk 传到手机，数据线、微信文件传输、网盘都行
2. 用文件管理器点开
3. 提示未知来源时，允许当前文件管理器安装
4. 打开应用，按引导给悬浮窗权限，设置里一般叫「显示在其他应用上层」
5. 点「让虫群上桌」，回桌面就能看见

**注意**

vivo / OPPO / 小米这类 ROM 可能杀后台，建议把电池策略设成「无限制」。悬浮窗上不了桌时应用会退回应用内显示，体检卡里会写原因。

这个 APK 用的是仓库里的测试签名（`android/app/maggot-shared.keystore`），仅供分发体验，不要拿它上架。

**卸载**

长按图标卸载，数据跟着一起删。

## 命名规则

```
MaggotTask-Windows-<版本号>.zip     Windows 免安装包，解压即用
MaggotTask-Android-<版本号>.apk     Android 安装包
```

版本号和源码里的 `versionName`、`csproj <Version>` 保持一致。正常发版会新增文件、保留旧版；修 bug 的补丁直接替换同平台旧文件，不把有问题的构建留在仓库里。

## 校验值

SHA-256 前 16 位：

| 文件 | SHA-256 |
|:--|:--|
| `MaggotTask-Windows-1.3.2.zip` | `fb9aed072b979594…` |
| `MaggotTask-Android-1.2.10.apk` | `f93b6b68087111b8…` |

完整校验用 `Get-FileHash .\MaggotTask-Windows-1.3.2.zip -Algorithm SHA256`。
